# Kitchen Chaos
Kitchen Chaos is a single player cooking experience, where players have to juggle between cutting, cooking, and preparing various dishes ordered by customers, players have to look out for things to prevent burning, and deliver maximum amount of orders
## Features
1. Modular Ingredient System [Easily Add New Ingredients]
2. Modular Counter System [Easily Add New Counters]
3. Delivery System [Customers can order variety of Recipes]
4. Full Game play loop [Mainmenu, loading, Game Scene]
5. Input Rebinding
6. Gamepad Support
